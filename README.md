# Help Desk Ticket Triager

Paste in a Help Desk ticket and get back a category, P1–P4 priority, first troubleshooting steps, and a draft reply.

## What it does
- Classifies tickets: Network & VPN, Email & Outlook, Password & Access, Hardware, Printer, Software, Security, Onboarding
- Scores priority P1 (Critical) to P4 (Low), with time-bound update promises
- Gives first steps and a send-ready reply draft

## Tested
10/10 test tickets passed on Nov 16, 2026, including a whole-floor Wi-Fi outage (P1), an Outlook sync failure (P2), and a phishing click (P2).

## Built with
HTML, CSS, JavaScript — a single-file web app, no install needed. Open help-desk-ticket-triager.html in a browser to use it.
